## ADDED Requirements

### Requirement: 验证可信状态与有效控件
强制门禁 SHALL 通过后端 API、真实前端组件和目标视口浏览器测试验证未知行情语义、零分母覆盖率、服务端告警筛选及能力感知区域。源码字符串断言 MUST NOT 作为这些行为的唯一证据。

#### Scenario: 未定价持仓回归
- **WHEN** 测试样例后端返回尚未取得行情的 legacy 持仓
- **THEN** API 契约返回可空派生指标，列表、详情和仪表盘均不显示虚构的 `0.00%` 或安全/临近判断

#### Scenario: 告警筛选跨分页
- **WHEN** 测试样例数据包含超过一页且名称、阅读状态和处置状态不同的告警
- **THEN** API 和真实 Alerts 组件验证筛选发生在分页前、URL 可恢复、总数正确且页面不存在无效筛选控件

#### Scenario: legacy 能力关闭
- **WHEN** 三个目标视口运行 legacy 能力测试样例
- **THEN** 仪表盘和设置页不显示风险预算区域，规划器导航保持隐藏，直接规划器路由继续稳定降级

#### Scenario: 空组合覆盖率
- **WHEN** 监控状态没有活动持仓
- **THEN** API 返回可空覆盖率且界面不显示 `100%` 可信覆盖
